Haushaltsfinanz herunterladen

Zwei Wege, dieselbe Versionsnummer: als Windows-Dienst auf dem eigenen Rechner oder als Container. Die Anwendung läuft im Heimnetz, und die Daten bleiben dort.

Windows

ZIP aus dem neuesten Release laden, entpacken, setup.cmd als Administrator starten. Alles Weitere holt das Setup selbst nach.

Zum neuesten Release

Docker

Image aus der GitHub-Registry; die Vorlagen für compose.yaml und .env liegen im Repository unter docker/. 

docker pull ghcr.io/schlotti73/haushaltsfinanz:latest

Einrichtung, Update und Rollback: docs/docker.md

1 — WindowsWas der Rechner mitbringen muss

Windows10 oder 11, 64-Bit
RechteAdministrator – das Setup fragt sie selbst ab
Internetwährend der Installation; danach nicht mehr nötig
App Installerder Befehl winget; er gehört zu Windows 10/11, fehlt aber auf manchen Systemen

Fehlt winget, meldet das Setup das vor der ersten Änderung und nennt die beiden Bezugswege: den „App Installer“ aus dem Microsoft Store oder das .msixbundle von winget-cli. Gebraucht wird er nur, solange Python und die Texterkennung noch fehlen – sind sie schon installiert, läuft das Setup auch ohne ihn.

Das Setup holt selbst nach, was fehlt:

  • Python – die Laufzeitumgebung der Anwendung,
  • Tesseract-OCR – die Texterkennung für Kassenzettel und Belege,
  • WinSW – den Wrapper, der die Anwendung als Windows-Dienst betreibt.

Alles Übrige liegt im Paket: die Python-Pakete als fertige Wheels, die Sprachdaten der Texterkennung und das vorgebaute Frontend. Node.js wird auf dem Zielrechner nicht gebraucht. Die genauen Versionen stehen in docs/betrieb.md im Paket.

2 — WindowsInstallieren

  1. ZIP freigeben: Rechtsklick → Eigenschaften → „Zulassen“ – sonst sperrt Windows die Skripte im Paket,
  2. entpacken,
  3. setup.cmd starten und die Administrator-Abfrage bestätigen.

Danach läuft die Anwendung als Windows-Dienst und ist im Browser erreichbar. Das Anmeldepasswort erzeugt der erste Start zufällig und zeigt es genau einmal an; gespeichert wird nur sein Hash.

Ausführlich – Ports, Zertifikat, Backup, Dienst-Verwaltung – in docs/betrieb.md, das auch im Paket liegt.

3 — DockerContainer einrichten

Kurzfassung: Ordner anlegen, compose.yaml und .env aus den Vorlagen übernehmen, starten. 

mkdir -p ~/docker/haushaltsfinanzen/daten && cd ~/docker/haushaltsfinanzen
docker compose up -d
docker compose logs app | grep -A4 "Erster Start"

Das Anmeldepasswort steht genau einmal im Log. Gemountet wird ein einziger Ordner (daten/) – darin Datenbank, Belege, Kontoauszüge, Backups und Einstellungen. Das Programm selbst steckt im Image und wird nie gemountet.

Alles Weitere – Update, Rollback, Reverse-Proxy, zweiter Faktor außerhalb des Heimnetzes – in docs/docker.md.

4 — Beide WegeUpdaten

Windows

Neues Paket entpacken und update.cmd starten. Oder, bei laufender Installation, unter Einstellungen → Programm-Update herunterladen und den dort genannten Starter doppelklicken. Steht eine Schema-Änderung an, legt das Update vorher eine Sicherung der Datenbank an – ohne Sicherung keine Migration.

Docker

docker compose pull && docker compose up -d

Denselben Befehl zeigt die Oberfläche, sobald eine neuere Fassung vorliegt. Die Sicherung vor einer Migration übernimmt hier der Containerstart.

Beide Wege tragen dieselbe Versionsnummer: das Windows-Paket liegt als Release im Repository, das Image trägt denselben Tag.
